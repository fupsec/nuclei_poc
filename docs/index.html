Why Nuclei POC

Built for scale, curated for quality

Automated pipeline that ingests, validates, deduplicates, and ranks templates from the security community.
Δ

Incremental Updates

Only fetches changed files since last sync via partial clone. Saves 99% bandwidth over full clones.

✓

Auto-validation

Every POC is validated with nuclei -validate. Invalid templates go to review directory for manual triage.

◎

Multi-factor Dedup

18-dimension similarity scoring: CVE/CNVD matching, URL+method analysis, matcher keyword comparison, and name similarity.

★

Quality Tiers

5-tier grading system ranks POCs by metadata richness, protocol support, detection capability, and format quality.

⚙

Auto-fix

Automatic severity casing normalization, empty severity completion, ID whitespace correction, and naming standardization.

↻

Progress Resume

State.json records each repo's HEAD commit. Fresh VMs resume from last progress — no redundant cloning on unchanged repos.

Quality Tiers

From comprehensive to elite

Each tier balances breadth and quality. Higher tiers = higher confidence.
Quick Start

Use with Nuclei

Download and scan with any tier in seconds.
# Clone only the gold tier (sparse checkout)
git clone --filter=tree:0 --sparse https://github.com/adysec/nuclei_poc
cd nuclei_poc && git sparse-checkout set poc_gold_15

# Scan a target
nuclei -t poc_gold_15/ -u https://example.com
# Or download all POCs
nuclei -t poc/ -u https://example.com
